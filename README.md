# VirDeck

**VirDeck** 是一款轻量、开箱即用的电脑端安卓多开桌面软件，支持 **Windows 10 / 11**、**macOS（Apple Silicon / Intel）** 与 **Linux**。

无需安装庞大的 Android Studio 或 Java，也不用折腾复杂配置——所有组件、安卓系统和手机数据都集中保存在一个文件夹里，方便随时备份或换电脑迁移。

---

## 它能做什么

- **多开与分组管理**：一键创建多台互相独立的安卓虚拟机，每台手机的应用、账号和数据互不干扰；支持按分组筛选、整组启动或停止。
- **后台省资源 + 多窗口投屏排版**：手机默认在后台安静运行，需要看画面时随时打开投屏窗口；支持快捷静音/有声切换、画质预设，以及多窗口一键平铺、记住位置和按分组保存桌面布局。
- **拖入即装应用**：把 `.apk`、`.apks` 或 `.xapk` 安装包直接拖进软件窗口或对应设备行，就会自动开机、安装并打开应用。
- **多台手机同步操作**：开启同步后，用鼠标操作主控手机画面，其他手机（即使没开投屏窗口）也能同步跟点（Windows 支持全局鼠标同步；全平台支持同步导航键与中英文文本发送）。
- **实用日常工具**：内置电脑与手机互传文件（发送图片自动进相册）、虚拟定位、一键批量截图、应用管理、单机独立代理、空间/磁盘清理以及单台手机一键备份与还原。
- **开箱即用与便携迁移**：软件内可直接下载所需运行工具和官方安卓系统，支持断点续传；日常关闭所有手机后，把整个文件夹复制走就能带到其他电脑继续使用。

## 三步快速上手

1. **下载并打开软件**：从 Releases 下载对应系统的程序并打开（Windows 直接运行 `VirDeck.exe`，同级会自动生成 `VirDeckData` 数据文件夹；macOS 运行 `VirDeck.app`）。
2. **补齐运行工具与安卓系统**：
   - 如网络无法直接连接 Google 下载组件，先点击左侧 **「设置 → 常规与下载」** 填写代理并保存。
   - 打开左侧 **「镜像与环境」**，点击 **「一键下载补齐缺失工具」**；再切换到 **「系统镜像」** 选择推荐的安卓版本（如 `Android 11` 或 `Android 14`）点击 **「下载安装」**。
3. **创建并使用手机**：点击右上角 **「+ 新建实例」** 创建一台或多台安卓手机；在列表中点击 **「启动」**，就绪后点击 **「投屏」** 即可操作，也可以直接把安装包拖进窗口安装。

## 使用前准备

- **Windows**：需在「启用或关闭 Windows 功能」中开启 **Windows 虚拟机监控程序平台**，并在主板 BIOS 中开启虚拟化；如放在中文路径下受限，可按软件提示一键切换为纯英文数据目录。
- **macOS**：支持 Apple Silicon 与 Intel 芯片；如需使用「投屏排版」自动整理窗口，需在「系统设置 → 隐私与安全性 → 辅助功能」中允许 VirDeck 控制窗口。
- **Linux**：需开启虚拟化并确保当前用户有 `/dev/kvm` 的读写权限。

> 各系统具体开启步骤与常见报错解决方法，请直接查看 **[使用指南 · 常见问题排查](docs/usage.md#14-常见问题排查-faq)**。
